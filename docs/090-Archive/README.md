# Archive

This directory is for docs that are useful historically but no longer active guidance.

## Archive Rules

Move docs here when:

- They describe removed tests or old file paths.
- They are completed implementation plans.
- They are duplicate drafts replaced by `docs/current`.
- They are generated reports kept only for audit history.

Do not move a doc here if it is still the only source for a current business rule.
